# Codomax Backend Blog App (Task 3 & Task 4)

A Node.js and Express RESTful API backend for the Codomax Blog Application.

## 🚀 Features & Endpoints
* **GET `/api/blogs`** - Fetch all blog posts (`200 OK`)
* **GET `/api/blogs/:id`** - Fetch a single blog post by ID
* **POST `/api/blogs`** - Create a new blog post

## 🛠️ Tech Stack
* Node.js
* Express.js
* CORS
